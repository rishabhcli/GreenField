Operator token

Governance routes compare a bearer token against OPERATOR_API_TOKEN in constant time and fail closed. Reads are gated too — approvals, budgets, orders, the audit chain, provider status, agent runs and the interaction feed all answer 403 without it. Without a token this console can show you nothing at all.

Stored in sessionStorage for this tab only. The audit chain's verified actor is operator — the token is the only identity the server checked. Your name is stored beside it as detail.operatorLabel, an unverified annotation for whoever reads the log later. Anyone holding the token can type any name, so it is a courtesy, not proof.
